标题

使用 # 表示标题，数量对应级别（1–6 级）。

段落与换行

  • 段落： 段落之间空一行。
  • 换行： 行尾加两个空格再回车，或直接空一行。

用 | 分隔列，--- 分隔表头与内容。对齐用 :。

转义字符

在特殊字符前加 \ 可输出原字符。

常用可转义字符：\ * _ # [] () ~ ` > | 等。

HTML 标签

Markdown 中可直接写 HTML，用于更复杂排版。

部分站点会过滤或限制 HTML，以实际环境为准。

语法 写法示例 说明

书写建议

  1. 标题前后空一行，便于解析。
  2. 列表、引用等块前后也建议空行。
  3. 代码块标明语言，方便高亮。
  4. 链接尽量用 [文字](URL)，可读性更好。
  5. 表格列对齐用 :---、:---:、---: 可提升可读性。

手册结束。可根据使用的平台（GitHub、Typora、VS Code 等）再查阅其扩展语法。
